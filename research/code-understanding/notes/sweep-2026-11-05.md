## Findings

### A. perspica — one new ranked item

- **What:** A local Rust binary. MIT. Beta. It parses both sides of a diff with tree-sitter. It collapses formatting, comment-only edits, rename-only lines, unchanged moves, and generated or vendored files, and it reports how many lines are left to read. The reading order walks changed code from entry points down to the changed functions they call. It says which changed tests reach which changed functions, and it shows the call path. The README says those three do not need a model. The homepage says reading order, mechanical changes, and test reach come from perspica itself, and that summaries, notes, and Learn lessons come from a model, with each lesson checked against the code. Languages named in the README include TypeScript, JavaScript, Python, Rust, Go, Java, Kotlin, Scala, C#, C, PHP, and Ruby. Other files stay line diffs.
- **Homepage examples, read on 2026-11-05.** Twelve merged pull requests. pmndrs/react-three-fiber#4008, "152 of 545". pallets/flask#5818 is on the page. That card's line count is 197 of 239. The backlog names the pull request. This note is where the ratio is written down. apache/spark#59118, "87 of 633", and "tests reach 30 of the 31 changed functions." jhy/jsoup#2618, "tests reach all 20 changed functions."
- **Stars.** GitHub API `stargazers_count` 41. The crate appears under the crates.io keyword `semantic-diff`.
- **X.** [vibeleaderboard](https://x.com/vibeleaderboard/status/2117626768110596353), 2026-11-03. `public_metrics` like_count 1, impression_count 26, bookmark_count 0, reply_count 1. The post is a tooling list. The perspica line is "puts a big diff in reading order."
- **Evidence:** `vendor`, plus `engagement` that is tiny.
- **Decision.** New ranked item, draft 5's #8. Status `proposed`, cost M, target HR. Measurement stays at #1 and #2. #3 through #6 stay above this item because their evidence is stronger or their cost is lower. It is its own row, next to blast radius. Blast radius answers what else a change touches. This item answers which lines are the logic, which order to read them, and which tests reach which changed functions. The homepage ratios are the vendor's examples. They are not a measurement of our reviewers. The test is a hand comparison on 5 to 8 real pull requests, including a check for false move collapses.

### B. Folds from perspica, not new rows

- **Asked versus agent's call.** For the author's own change, perspica can read a local Claude Code or Codex session and show the prompts. With the optional model pass, a group is marked *asked*, with a short quote checked word for word against those prompts, or *agent's call*. The README says sessions are not read for someone else's pull request. Cited on #5 only.
- **Learn.** At most three concepts for one change, or "nothing to learn" for formatting, renames, and changes that need no background. Each concept can include a figure and a quiz of one to three questions. Lessons are model-written, then checked against the code. Cited on #1 (the quiz), #3 (the short lesson), and #15 (the figure, when one is drawn). Not cited on #4. A worked example in this backlog is one traced input whose values come from a recorded command. Learn's figure is a concept lesson. Those are different blocks.

### C. DiffGuardian — voice, Trace It, Ask, a graph, and two unranked views

The page describes a dependency graph "built from the diff alone (heuristic, not AI)." Plans turns an agent plan into a summary, a diagram, and a data model. Worktrees follows agents in their own git worktrees and redraws the graph while files change. No star count was fetched. No repository URL was on the page I read.

- **Use:** voice and Trace It on #15. Ask on #6. The graph on #7. Plans and Worktrees are a possible later limitless spike, noted on #16, not ranked.
