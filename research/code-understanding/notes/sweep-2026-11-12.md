### A. pr-tour — one new ranked item, rank 7, heading 18

- **What is new against human-review.** The author's words, quoted verbatim, mapped to the files
  that implement them, plus the changed non-noise files that no quote explains. Intent status is
  `spec`, `described`, `title only`, or `UNKNOWN` (`intentStatus` in `lib.mjs`). The gate rejects a
  non-verbatim quote. The skill says to run in a fresh session, never the one that wrote the diff.
  Human-review already reads the description and the commit messages, writes its own brief, groups
  files in `concerns`, orders reading with `focus`, tiers mechanical and generated files, and asks
  the reviewer `questions`. Its precision check tests the page's claims. Its signals ignore the
  pull request text. None of that is this map.

  collapsed (lockfiles, generated files, renames, formatting). Tests next to code. At most eight

  published 2026-11-09T09:01:27Z. The HTML and the API entry were read in this session. The numbers
